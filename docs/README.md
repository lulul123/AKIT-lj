# A-KIT 文档导航

## 当前技术路线

当前唯一有效的目标路线是：

```text
每秒 IMU + 速度 + PStart
              ↓
网络输出 15 维 Qc 缩放因子
              ↓
使用当前秒内的全部单步 Phi/dt 逐步传播协方差
              ↓
使用 H/R/Inno/GNSSMech 重建 GNSS 更新
              ↓
与参考 ECEF 位置计算损失
```

`PhiAcc/QAcc` 是旧路线，不再作为当前数据或训练接口。
