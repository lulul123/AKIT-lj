# A-KIT 服务器迁移与训练说明

## 1. GitHub 与数据的边界

GitHub 保存：

- `Code/`：训练、模型接口、运行时和数据/Kalman 公共代码；
- `configs/`：标准训练配置；
- `schemas/`：数据和训练配置 Schema；
- `tools/`：数据、配置和 PPred 数值检查工具；
- `data/datasets.json`、`data/README.txt`：数据目录元数据；
- `docs/`：项目说明；
- `requirements.txt`：已验证的 Python 包版本。

GitHub 不保存：

- `data/data*/` 下约 18 GB 的真实轨迹；
- `.venv/`；
- `runs/`、checkpoint、权重和日志；
- `copy/`、`refcode1/`、`refcode1029/` 等本地重复参考源码；
- PDF 论文和其他不影响运行的大文件。

因此，仅在服务器执行 `git clone` 还不能训练，必须另外传输数据。

## 2. 服务器克隆代码

```bash
git clone https://github.com/lulul123/AKIT-lj.git
cd AKIT-lj
git switch agent/reproducible-akit-workflow
```

如果该分支后续合并进 `main`，服务器直接使用 `main` 即可。

## 3. 传输数据

在当前电脑执行，替换服务器用户名和地址：

```bash
rsync -avh --progress data/data013325 user@server:/path/to/AKIT-lj/data/
rsync -avh --progress data/data065517 user@server:/path/to/AKIT-lj/data/
rsync -avh --progress data/data090854 user@server:/path/to/AKIT-lj/data/
rsync -avh --progress data/data122041 user@server:/path/to/AKIT-lj/data/
rsync -avh --progress data/data212832 user@server:/path/to/AKIT-lj/data/
```

也可以传整个集合：

```bash
rsync -avh --progress --include='data*/***' --exclude='*' \
  data/ user@server:/path/to/AKIT-lj/data/
```

传输后目录必须保持：

```text
AKIT-lj/
├── data/
│   ├── datasets.json
│   ├── data013325/
│   ├── data065517/
│   ├── data090854/
│   ├── data122041/
│   └── data212832/
├── Code/
├── configs/
├── schemas/
└── tools/
```

## 4. 创建 Python 环境

推荐 Python 3.10，与当前验证环境一致：

```bash
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
```

PyTorch 应根据服务器 NVIDIA 驱动和 CUDA 环境，从 PyTorch 官方提供的对应安装命令
安装。不要直接复制本机 `.venv`，因为二进制包、CUDA 和路径可能不兼容。

安装 PyTorch 后，再安装其余依赖，或在确认 CUDA wheel 来源正确后执行：

```bash
python -m pip install -r requirements.txt
```

## 5. 训练前验收

先运行无需真实数据的检查：

```bash
python tools/validate_training_config.py configs/akit_set_transformer.json
python Code/smoke_test.py
python tools/check_server_ready.py --skip-data
```

数据传输完成后运行：

```bash
python tools/check_server_ready.py
python tools/validate_dataset.py --all --max-records 1000
```

检查 CUDA：

```bash
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
```

## 6. 先小规模训练

```bash
python Code/A-KIT_lj_agent.py \
  --config configs/akit_set_transformer.json \
  --small --epochs 1 --max-samples 20
```

确认 loss、梯度和 checkpoint 正常后，再运行正式训练：

```bash
python Code/A-KIT_lj_agent.py \
  --config configs/akit_set_transformer.json
```

训练结果写入 `runs/`，该目录不进入 Git。需要长期保存时应复制到服务器实验存储、
对象存储或单独的模型仓库。

## 7. 后续更新

本地提交并推送后，服务器进入仓库执行：

```bash
git pull --ff-only
python tools/validate_training_config.py configs/akit_set_transformer.json
python Code/smoke_test.py
```

数据文件不随 `git pull` 改变。如 catalog 新增轨迹，需要再次单独传输对应数据目录。
