## 小规模真实数据诊断

```bash
python Code/A-KIT_lj_agent.py \
  --small \
  --data-root data_lj \
  --train-dirs data065517 \
  --val-dirs data212832 \
  --max-samples 32 \
  --epochs 1 \
  --batch-size 8 \
  --device auto
```

用途：使用已经生成累计矩阵的新格式数据，快速检查真实数据读取、训练和结果保存。它不是正式实验。

每个数据目录至少需要：

```text
imu.txt
Vel.txt
PStart.txt
PhiAcc.txt
QAcc.txt
H.txt
R.txt
Inno.txt
NominalState_prior.txt
位置参考文件
```

## 正式训练示例

```bash
python Code/A-KIT_lj_agent.py \
  --data-root data_lj \
  --train-dirs data065517 data090854 data122041 \
  --val-dirs data212832 \
  --epochs 50 \
  --batch-size 32 \
  --learning-rate 0.005 \
  --device auto
```

保留 `data013325` 作为最终测试轨迹，不在训练或选模型期间读取。

## 数据划分规则

- `--train-dirs` 与 `--val-dirs` 必须互不重叠；
- 每个目录视为一条完整轨迹；
- 不允许把同一轨迹的相邻样本随机拆到训练集和验证集；
- 最终测试轨迹不能用于超参数选择；
- 归一化统计量只由训练集计算。

## 常用参数

| 参数 | 含义 |
|---|---|
| `--data-root` | 数据根目录 |
| `--train-dirs` | 训练轨迹目录名列表 |
| `--val-dirs` | 验证轨迹目录名列表 |
| `--epochs` | 训练轮数 |
| `--batch-size` | 批大小 |
| `--learning-rate` | 学习率 |
| `--device auto/cpu/cuda` | 运行设备 |
| `--small` | 启用诊断模式 |
| `--max-samples` | 诊断模式最大样本数 |
| `--run-overfit` | 运行单批过拟合诊断 |

完整参数以以下命令为准：

```bash
python Code/A-KIT_lj_agent.py --help
```

## 结果输出

结果默认保存在：

```text
runs/<experiment_name>_<timestamp>/
```

主要内容包括：

- `config.json`：本次参数；
- `environment.json`：Python、PyTorch、CUDA 和 Git 信息；
- `split_manifest.json`：训练/验证轨迹与样本数；
- checkpoint：模型、优化器、随机状态和指标；
- 根据输出开关生成的预测、图像或分析文件。

## 当前限制

当前累计器尚未在完整 C++ 工程中编译并生成首批新数据。正式训练前必须使用
`PStart.txt/PhiAcc.txt/QAcc.txt/PPredCpp.txt` 完成区间累计一致性验证。当前累计器按整数秒重置；GNSS 缺失或质量控制拒绝场景尚未改为按“成功量测更新”重置。

## 推荐执行顺序

```text
1. smoke_test.py
2. --small真实数据诊断
3. 验证 PPredCpp ≈ PhiAcc·PStart·PhiAccᵀ + QAcc
4. 固定Q/恒等缩放复现
5. 正式轨迹级训练
6. 独立测试轨迹评价
```
